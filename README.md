# YS261 学生小组互评系统（演示版）
## 启动
直接双击 `index.html`，或上传到任意静态网页托管平台即可访问。
## 默认管理员密码
`YS261-admin`。登录后可修改密码、编辑学生名单、清空评价数据。
## 当前功能
- 实名自评：评价对象自动为本人
- 实名互评：记录评价人，禁止评价自己
- 匿名互评：不显示/记录评价人，禁止评价自己
- 5项评分，每项0–20分，总分100
- 成绩看板、互评均分、综合分（自评50%+互评50%）
- 导出CSV
- 学生名单管理（默认36个“学生01…学生36”，管理员可替换）
## 重要说明
本版本是可运行前端演示，数据存在浏览器 localStorage。不同设备/浏览器之间不会共享数据，也没有真实账号权限验证。
如果需要全班36人通过同一个网址在线提交并实时共享，需要部署服务器端接口与数据库（例如 Supabase/Firebase/MySQL），并设置真实管理员认证。不要把演示版密码当作安全凭据。
